# ICU Patient Management System (PDMS) — End-to-End Enterprise Project Management Portfolio

##  Project Executive Summary
This repository contains the complete, executive-ready Project Management Portfolio, Strategic Proposal, and System Governance Framework for an enterprise ICU Patient Management System delivered by `$oft ₵orp` for a standalone hospital ICU. 

The primary mission of this 12-month, 15-person project was to architect a high-availability ($99.99\%$ uptime targets) web-based intranet platform capable of normalizing and streaming live, near-real-time medical device telemetry (<1 second refresh latency) directly into clinical dashboards to mitigate alert fatigue and reduce manual transcription errors. 

As the Lead Project Manager & Product Owner, I governed this multi-disciplinary project through its complete lifecycle, managing an initial baseline budget of $1,826,620 (scaling to $2,350,942 with an integrated 12-month post-deployment tier-0 to tier-3 support contract)[cite: 5].

## Project Management Artifacts & Core Deliverables

This project's engineering and management phases are meticulously structured into the following portfolio directories:

### 1. Project Initiation & Chartering 
Project & Team Charters: Formulated the foundational Project Charter mapping clear milestones, cost structures, and executive approval chains alongside a Team Charter defining operational norms, communication values, and organizational vulnerabilities.
Stakeholder Power-Interest Matrix:Conducted a comprehensive stakeholder analysis segmenting key figures (Hospital Executive Sponsors, ICU Nurse Leads, Compliance/Legal Auditors, and Dev Teams) into a Power-Interest Grid to govern ongoing communication strategies.

### 2. Requirements Engineering 
Software Requirements Specification (SRS): Authored a detailed SRS outlining 27 functional constraints (including multi-factor authentication badge tapping, 12-hour shift handoff reporting, hands-free speech-to-text API integration, and automated local edge server failover triggers) and strict non-functional rules (HIPAA data governance, 1,000 concurrent user limits, and end-to-end encryption protocols).
Clinical Use-Cases & Agile User Stories: Developed granular interaction workflows for ICU Control Center Administrators (e.g., threshold configuration models) along with comprehensive user stories mapped out with concrete business acceptance criteria.

### 3. Work Breakdown Structure & Scheduling 
Multi-Tier Work Breakdown Structure: Engineered a hierarchical WBS decomposing the entire ecosystem into independent branches across Frontend UI, Backend Architecture, Data Layer Systems, and Post-Implementation Operations.
Hybrid Timeline & Gantt Charting: Calculated work packages using Story Point estimation across a 4-phase development runway, visually locking in task dependencies, testing cycles (Security, Stress, and Clinical Logic validation), and critical paths via ClickUp.

### 4. Agile Backlog & Sprint Planning
Jira Workspace Sprints: Organized the development timeline into explicit 2-week active Scrum sprints.
Epic and Story Allocations: Tracked individual task assignments through concrete Jira components—including API buildouts, device connectivity alerts, theme optimization, and CI/CD automated reporting services.

### 5. Governance, Risk Management & Communication 
Quantitative Risk Register: Identified 19 critical failures spanning Technical, Financial, Schedule, and People risk categories[cite: 5]. Built a live risk matrix scoring events by Probability/Impact (e.g., Nurse Alert Fatigue, WiFi Signal Interferences, and Cloud Server Failures) complete with mitigation pathways and mitigation owners.
Meeting Cadence Matrix: Structured an enterprise communication plan covering Agile daily standups, bi-weekly stakeholder sprint reviews, monthly executive steering summaries, and immediate automated incident response thresholds.

### 6. Financial Controls & Resource Management
Bottom-Up Cost Plan: Documented human capital assets across a 13-person full-time engineering grid (totaling 21,440 productive project hours), accounting for software licensing, clinical-grade tablet procurement, and legal compliance audits.
RACI Matrix & Cashflow Mapping: Established clear task accountability parameters using a formalized RACI matrix alongside a monthly operational cashflow table tracking direct labor, overhead buffers, and a 10% cash contingency reserve.

### 7. Project Closure & Operations Maintenance
Post-Mortem & Lessons Learned: Documented operational achievements (97% speech-to-text accuracy in noisy environments, successful local failover tests) and analyzed architectural shortfalls (initial workflow alert noise and clinical onboarding bottlenecks).
12-Month Support Proposal: Engineered a 4-tier ITIL service desk structure (Tier 0 Self-Service Knowledge Bases up to Tier 3 Senior On-Call Engineering groups) bound by a strict Service Level Agreement (SLA) guaranteeing 99.9% application availability and a Mean Time to Repair (MTTR) of <4 hours.
